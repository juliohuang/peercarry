# 跨设备账号库：实施边界 v0.1

状态：2026-09-24 用户已选择跨设备方案。本文件是新增功能设计，不代表已有安装包支持密码库。现有登录协助的单次配对不能直接当作长期账号库的设备授权。

## 功能

独立账号库覆盖系统/服务器、数据库、Redis、网站。每项包含名称、类别、环境、地址、端口、用户名、密码、数据库名、TLS 选项、用途、标签、修改时间及可选到期提醒。非适用字段不显示。名称、地址、备注和账号同样属于加密内容。

桌面与手机支持新增、编辑、搜索、分组、删除和恢复；密码默认遮盖，解锁后用户主动查看。首版不连接数据库执行 SQL，不自动登录 Redis/SSH，不自动把密码注入 AI，不处理私钥文件、TOTP 种子或密码管理器导入。

## 加密与解锁

- 在端侧加密整个账号记录；任何同步设备仅接受版本化、长度受限的密文对象，普通协调与通知不含条目正文。
- 使用成熟密码学库的认证加密，独立随机 vault key；主密码经标准 KDF 派生包装密钥后加密 vault key。算法、参数、版本与库 ID 绑定认证数据；随机数来自操作系统。
- 主密码不发送到其他设备或服务端。首次加入另一台设备需要现有设备批准，再在新设备本地解锁同一账号库。
- 生物识别/系统钥匙串只作为后续可选本地解锁便利，不是跨设备密钥同步方式。首版不默认长期记住解锁密钥。
- 自动锁定、切后台锁定、屏幕锁定、退出时清理可控敏感缓冲区；明确无法承诺清除所有 OS/托管运行时内存副本。
- 忘记主密码且没有离线恢复材料时无法恢复数据；恢复材料不进入普通剪贴板、聊天或云日志。

## 同步与冲突

- 建立独立的账号库设备成员列表，Tailscale 连通不等于有账号库权限。
- 设备配对和账号库加入分别批准；通知链接不能授权加入或解锁。
- 同步对象带库 ID、条目随机 ID、操作随机 ID、父版本、密钥代次、设备身份与签名；密文和版本元数据一并验证。
- 不以设备时间判断覆盖关系。并发编辑保留两份加密分支，解锁后由用户选择；删除传播墓碑，旧设备上线不能自动复活已删除记录。
- 去重、防重放、长度限制、逐库限流；在本机保存已见版本，拒绝可检测的回退。新设备无本地版本基线时须与可信已有设备确认状态。
- 移除设备阻断后续同步并轮换后续数据的密钥；不能收回已泄露或已被该设备解密的旧凭据，必要时需去原系统修改密码。

## 与现有功能隔离

账号库不写入剪贴板条目、历史、普通文件导出或 AI 事件。不复用公开的剪贴板 HTTP API。现有设备发现仅帮助发现连接地址。

首版不提供密码复制按钮，避免系统剪贴板和其他监听软件获取秘密。后续定向填写必须用户选定单条凭据，核实远端真实域名并按登录协助授权链执行；AI 无权搜索密码库或读取条目秘密。

## 开发与验收顺序

1. 独立 Rust 密文格式、密钥包装、账号模型和本地加密存储。验证错密码、篡改、截断、随机 nonce、错误库 ID、锁定清理与原子保存。
2. 已配对设备间的专用同步协议。双进程验证首次同步、离线重连、并发修改、删除、重放拒绝与成员撤销。
3. 桌面账号库界面与 Flutter 手机解锁、列表、编辑和冲突处理。客户端网络抓取与日志检查不得出现合成秘密。
4. 真实双机/手机验收：创建到同步、修改到同步、断网到合并、撤销到拒绝，以及备份恢复。没有通过前不标记可存生产密码。

敏感数据和权限设计由主代理负责；可将不含凭据的 UI、模型测试或说明委派给 Luna，提交前统一复核。当前仓库有大量未提交的既有开发，实施时避免覆盖登录协助和移动连接模块的改动。
