# 跨设备账号库开发记录

2026-09-24：已开始正式代码实现。本轮交付是独立加密内核和可接入的 Flutter 页面组件，**尚不是跨设备可用产品**，未加入发布包。

## 本轮代码

- `crates/peercarry-vault`：账号类型、端侧加密、随机数据密钥与主密码包装、锁定、密文序列化、加密删除墓碑、并发分支合并及显式冲突解决。
- `storage`：密文检查点按内容哈希保存；临时文件写入并刷新后再重命名；加载验证哈希与认证加密。调用方保留可信版本，不根据文件时间选择“最新”。
- `apps/mobile/lib/vault_page.dart`：独立 controller 驱动的账号库页面组件；未配置 controller 时不可用，不能假装已同步。不会接入剪贴板 HTTP 服务。

账号名称、地址、用户名、密码、数据库名、备注、标签和提醒时间均在密文内。同步结构仍可暴露随机 ID、版本关联、大小和记录数量；不宣称隐藏访问模式。

## 已验证

- 新内核 7 个测试：错误密码、篡改、跨库拒绝、两个独立副本的并发编辑与解决、删除和旧副本合并、锁定、nonce 不重复样本、磁盘截断与非法路径。
- 新内核 `cargo clippy -p peercarry-vault --all-targets --offline -- -D warnings` 通过。
- Flutter 账号库 9 项组件测试通过；覆盖模拟 CRUD、分类搜索、密码遮蔽隔离、后台关闭编辑框、迟到解锁结果失效、固定错误提示和未接入状态。`flutter analyze lib/vault_page.dart test/vault_page_test.dart` 无问题。
- 主代理复核并修复了页面筛选后的密码显示状态复用、后台双重弹窗退出、可选字段校验及异步状态提示问题。组件测试使用假控制器，不能证明真实密钥桥接或网络同步。
- 工作区 `cargo test --workspace --offline` 通过；测试日志位于本地忽略目录 `target/vault-workspace-tests.log`。
- 两副本测试在同一进程运行，**不是双机网络同步或手机验收**。

## 未完成的接入

1. 独立账号库成员授权、设备签名、防撤销重放和密钥轮换。
2. 专用同步传输及持久化版本基线；新设备加入需要已有可信设备批准。
3. Rust 到 Flutter 的本地安全桥接、自动锁定实际密钥、桌面入口、冲突与恢复界面。
4. 主密码更换/恢复材料、备份恢复、操作系统锁屏事件、真实设备验收。

当前 `merge` 接口要求调用方先完成对端授权，不是可直接暴露的网络端点；持有库密钥的调用者能够写记录，当前格式没有设备作者签名。成员权限和网络层完成前不能存放生产凭据。原有移动连接与登录协助的配对权限不会自动升级为账号库权限。
