## 目标与首版边界

在 PeerCarry 中增加独立的登录协助能力：AI 申请 → 执行器确认暂停 → 手机确认目标与授权 → 原电脑原 Chrome 会话内登录 → 用户交还 → 撤销私密通道 → 执行器确认恢复。首个真实环境为自有 Mac、Chrome、iPhone。

首版支持登录区域查看、定向输入、区域内点击、用户确认扩大范围，以及拒绝、取消、断线和超时。暂不提供全桌面远控、密码库、自动跨域授权、锁屏绕过或通用桌面自动登录。ChatGPT 云浏览器、Grok Bot 等分别验证适配，不能因本机扩展安装成功便宣称支持其内部执行环境。

## 与现有项目的关系

- `peercarry-core` 的设备发现、Tailscale 连通性和 AI 状态通知可作为集成入口；现有 Hook 事件不是可靠的暂停确认。
- 登录请求及审计使用独立的数据模型，不生成剪贴板条目，不复用普通文件上传、历史同步和剪贴板导出通道。
- `peercarry-automation` 未来作为受控执行器之一接入资源锁；必须验证它和其他自动化程序都能实际停止相关读写操作。
- `apps/mobile` 可复用设备列表与导航；新增登录请求页、真实域名确认、私密画面和临时输入。现有 Flutter 项目不代表 iOS 登录协助已可用。
- 首版由 Rust 本机模块承担状态协调；Go 协调服务作为独立可选部署，P0 不新增重复的网络服务。其边界只允许设备在线状态、请求状态、通知和脱敏审计，不承载画面或凭据。

## 模块与信任边界

| 模块 | 职责与限制 |
|---|---|
| Rust 状态内核 | 请求、授权、有效期、状态转换、互斥资源租约、防重放；不接收普通聊天中的秘密 |
| Mac 平台适配器 | 按批准窗口采集，在电脑端裁剪后编码；权限拒绝或坐标失效即停止 |
| Chrome MV3 扩展 | 核实浏览器实例、标签页、文档、frame、origin 与字段，执行一次性定向输入 |
| Native Messaging 桥 | 固定允许的扩展身份、严格消息类型和大小校验；禁止任意网页转发本机命令 |
| Flutter iOS 客户端 | 配对、目标确认、单次授权、输入、拒绝与交还；密码不进入普通剪贴板 |
| 执行器适配器 | 受控 pause/resume 与真实确认；无可靠暂停能力时拒绝启动接管 |

手机与电脑经设备认证的加密通道直接交换私密数据。Tailscale 仅提供私网连接，不能代替每个设备的身份验证和每次操作授权。配对需要本机确认及短时一次性挑战；撤销手机后立即失效其连接与授权。

## API 与命令约束

AI 仅可使用 `login_assist.request`、`login_assist.status`、`login_assist.cancel`。API 返回请求 ID、脱敏状态、错误码、登录结果与恢复结果；不得返回密码、验证码、Cookie、画面或网页正文。AI 请求中的网址仅是提示，不是可信 origin。

执行器提供独立的 `pause` / `resume` 契约，确认必须绑定请求、任务、控制资源、适配器身份和本轮随机挑战。发送暂停命令不等于获得确认；客户端自报 `paused=true` 也不能作为验证依据。

手机授权与操作经独立认证入口进行，不向 AI 注册批准、填写、扩大范围和交还工具。每个私密命令至少绑定：

`request_id / device_id / browser_instance / tab_id / document_id / frame_id / origin / field_id / authorization_id / epoch / command_id / expires_at`

点击额外绑定 `capture_revision`、批准操作区域与坐标映射；查看范围与操作范围独立保存。页面导航、frame 替换、窗口变化、授权撤销均递增 epoch，旧命令一律拒绝。只有采集版本和实时布局一致时才执行点击。输入不支持时明确报错，密码不得退化为系统焦点键入或复制粘贴。

建议错误码包括 `PAUSE_UNSUPPORTED`、`PAUSE_FAILED`、`RESOURCE_BUSY`、`TARGET_CHANGED`、`OUT_OF_SCOPE`、`STALE_CAPTURE`、`AUTH_EXPIRED`、`REPLAY_REJECTED`、`INPUT_UNSUPPORTED`、`CHANNEL_LOST`、`RESUME_FAILED`。实现可调整命名，必须保留可区分的失败语义。

## 状态机与控制权

主路径：`requested → pause_pending → awaiting_user → active → handback_pending → resume_pending → completed`。

- 先预占资源并等待真实暂停确认，再向手机开放接管。浏览器内操作至少独占目标会话；涉及系统输入时独占整个交互桌面的自动操作资源。
- 手机批准只允许从等待用户状态进入 active；批准范围必须是明确显示且未过期的目标。
- 用户完成登录不直接置 completed。先关闭人工输入和画面通道、撤销授权、清除排队命令及画面，再申请恢复。
- 仅在执行器确认恢复后置 completed。分别记录 `login_result` 与 `resume_result`；登录成功但恢复失败显示“登录完成，任务仍暂停”。
- 拒绝、取消、超时、断线或恢复失败均关闭敏感通道并保持暂停。恢复必须再次走明确交还及确认流程，不因重连或租约超时自动恢复。
- 进程重启后不恢复旧授权或重放输入；未知状态进入人工处理。资源锁不能因请求超时就让另一个 AI 抢占仍处于人工控制中的资源。

## 隐私与失败处理

密码、验证码与 Cookie 不进入日志、审计、通知、数据库、崩溃附件、模型参数、普通剪贴板或跨机剪贴板同步。凭据只在本次通道内短时驻留；支持缓冲区清理的实现应及时清理，并明确托管运行时无法保证消除所有内存副本。

审计采用字段白名单：事件类型、随机请求 ID、授权变化、结果码和时间，不记录用户输入或任意错误正文。画面在电脑裁剪，默认不持久化；禁止服务端用完整画面供手机遮挡。通知链接只能定位请求，不能批准请求。

取消不代表网站退出登录；已有会话保留时应清楚提示并提供单独退出路径。助手不能对仍有管理员权限、独立截屏或浏览器配置读取能力的 AI 保证凭据不可见。更高隔离需要独立用户或执行环境，不应靠 UI 文案宣称已经实现。

| P1 首版闭环 | Flutter iOS、设备配对、加密直连、真实暂停恢复适配、独立授权与脱敏审计 | 下列 18 项全部有证据，未支持项不可用且说明原因 |
| P2 平台扩展 | Windows、Android、多设备路由、指定桌面应用与密码管理器专项适配 | 每个平台分别运行相同边界测试，不继承 Mac 的验收结论。Windows/Android 当前有原型实现，不等于本阶段验收通过 |
| P3 执行平台接入 | ChatGPT、Grok Bot、Codex 等适配器 | 每种执行环境验证真实暂停、原会话延续、恢复确认及权限隔离 |

## 18 项验收标准

18 项仍是完整产品验收门槛，不能因个别 Windows 本机 E2E 场景覆盖就标记整项或整体通过。已由当前 E2E 覆盖的合成浏览器场景可在 [`apps/login-assist-browser/TESTING.md`](../../apps/login-assist-browser/TESTING.md) 查证；真实手机、跨设备网络、Mac、外部 AI 暂停/恢复、实际网站登录等仍为“待验收/未验证”。逐项记录版本、环境、步骤、预期、实际和证据路径；模拟通过标为“模拟”。仅使用合成测试凭据。

| # | 场景 | 可验证通过标准 |
|---|---|---|
| 01 | 同会话完成 | 记录原标签页与会话 ID；手机操作后原测试任务在同一会话继续，无 Cookie 导出 |
| 02 | 真实暂停 | 延迟或拒绝暂停确认时，手机无画面和输入权；适配器确认后才开放 |
| 03 | 并发互斥 | 两个请求竞争同一资源，最多一个 active；系统输入场景覆盖整个桌面 |
| 04 | 配对与撤销 | 未配对设备不能看画面或操作；撤销后已有连接和授权立即失效 |
| 05 | 可信目标 | 网页伪造域名描述无法改变手机展示的真实 origin；不支持的 frame 拒绝输入 |
| 06 | 电脑端裁剪 | 在批准区域外放测试标记，捕获传输数据中不存在该标记及区域像素 |
| 07 | 范围分离 | 批准扩大查看不扩大操作；越界点击拒绝且无副作用 |
| 08 | 定向输入 | 改变系统焦点仍只允许绑定字段接收；字段不支持时无剪贴板或盲打回退 |
| 09 | 目标变更 | 切换域名、文档、frame 或目标后，旧授权输入拒绝，新目标需再次确认 |
| 10 | 坐标失效 | 窗口移动、缩放、滚动和布局变化后旧 capture_revision 点击拒绝 |
| 11 | 防重放 | 相同 command_id 重发不重复填写或点击；旧 epoch、过期授权均拒绝 |
| 12 | 断线与重连 | 输入中断线后停止敏感动作，重连不重放密码、不自动登录、不自动恢复 |
| 13 | 拒绝取消超时 | 各路径撤销授权并关闭通道；原执行器保持暂停且结果明确 |
| 14 | 安全交还顺序 | 验证关闭通道、撤销授权、丢弃队列均早于 resume；旧命令不能在恢复后执行 |
| 15 | 恢复失败 | 注入 resume 失败，登录成功与恢复失败分开显示，不能显示全部完成 |
| 16 | 隐私留痕 | 扫描日志、通知、数据库、AI 记录、崩溃附件和剪贴板历史，无合成秘密或画面正文 |
| 17 | AI 权限边界 | AI 凭证只能申请、查询、取消，不能批准、读秘密、填字段、导出 Cookie 或扩大范围 |
| 18 | 故障与权限拒绝 | 拒绝屏幕权限、杀进程、Native Messaging 来源伪造等均失败关闭；重启不复活授权 |

验收必须同时给出“登录成功”和“执行器已恢复”证据；UI 演示、状态单元测试和真实跨设备测试分别报告。
