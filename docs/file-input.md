# 文件选择与拖放入口

时间线顶部提供“选择文件”“选择文件夹”和拖放说明。桌面应用窗口接收拖入的多个文件或文件夹，复用 `SendFiles` 的捕获与广播流程；其他电脑仍按需下载，不自动覆盖剪贴板。源文件必须保留到对端下载完成。

文件路径由操作系统文件框或原生拖放事件提供，网页 IPC 只允许请求打开选择器，不能提交任意本机路径。嵌入窗口限制在本机时间线页面，防止外部网页使用原生入口。浏览器版禁用原生选择按钮并显示提示，阻止拖放导致页面跳转。
