# PeerCarry 桌面界面改版

本次先用内置 imagegen 生成视觉参考，再用现有 HTML、CSS 和 JavaScript 实现真实界面。设计稿为 `imagegen-concept.png`，完整提示词保存在 `imagegen-prompt.md`。图中的设备和内容仅作示例，应用读取实际设备与记录，不内置示例数据。

## 操作简化

- 工作台先选择设备，再发送剪贴板或获取对方内容。选择设备本身不会读取、发送或覆盖剪贴板。
- 选好电脑后，历史条目右侧的「发送」直接加入该设备的发件箱，默认等待 24 小时；不用跳转页面。
- 点击历史行只选中它，明确点击「复制」或按 Enter 才复制。获取对方内容仅加入历史。
- 传输记录优先显示结果；新建发送、有效期、路径和错误详情按需展开。
- 桌面侧栏聚焦工作台、传输记录和 AI 提醒；连接手机与设置保留在次要位置。
- 快捷面板沿用相同颜色与控件样式，发送和获取垂直排列，历史列表支持独立滚动。

## 视觉与适配

米白背景、白色卡片、青绿色主操作，使用系统字体和内嵌 SVG 图标，不引入远程字体、图片请求或前端依赖。窄窗口采用顶部导航和内容换行；中英文按系统浏览器语言显示。现有通信协议、认证与剪贴板边界保持不变。
