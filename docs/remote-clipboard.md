# 获取指定设备当前剪贴板

在共享历史页面选择设备，点击“获取当前剪贴板”。此操作会让目标设备即时捕获当前内容，并把条目加入本机历史；不会用目标设备的旧历史代替当前内容，也不会自动改写任何一端的剪贴板。

## 使用前提

两端升级到支持该功能的版本并连接 Tailscale。在被读取的电脑上打开设置，启用“允许对端读取当前剪贴板”，保存并重启。对应配置为：

```toml
[node]
allow_remote_capture = true
```

默认关闭。此权限允许具有服务访问权限的对端主动读取尚未手动分享的剪贴板内容；不需要开启 `allow_remote_apply`。已配置共享 token 的设备仍需认证。

## 行为

- 按 Tailscale 节点 ID 精确选择设备，避免同名或名称部分匹配造成误选。
- 获取文本后，在历史中显式复制；图片和文件仍按需拉取，文件源必须保持可用。
- 设备离线、未运行新版本服务、认证失败、读取未授权、剪贴板为空或不支持时显示失败。
- 设备刷新可重新发现在线设备。获取期间禁用重复点击。
- `GET /v1/peers` 与 `POST /v1/actions/fetch-clipboard` 仅接受 loopback 请求，后者请求体为 `{"node_id":"目标节点ID"}`。
- 目标端 `POST /v1/actions/capture` 的远程权限独立由 `allow_remote_capture` 控制；本机手动捕获仍可使用。

## 验证

自动测试覆盖读取权限与远程改写权限的隔离、本地入口限制、HTTP POST 与认证头、远端拒绝/空剪贴板错误以及重定向不跟随。测试使用合成条目，不操作用户的系统剪贴板。

双机验收需在目标电脑开启读取权限，复制新的测试文本，再从本机选择该设备获取；确认历史出现该文本，并确认两端剪贴板未被获取动作改写。图片、文件及空剪贴板应分别验收。
