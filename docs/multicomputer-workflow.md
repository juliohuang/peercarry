# 多电脑快捷操作、提醒切换与传输队列

这些能力已接入当前源码。使用新构建的托盘和服务；现有安装包不会自动获得工作区改动。

桌面端自动跟随电脑显示语言使用中文或英文，无需手动设置；详见[中英文适配与验证记录](desktop-language.md)。

## 快捷面板

从托盘或时间线的「快捷面板」打开。Windows / Linux X11 使用 `Ctrl+Shift+Space`，macOS 使用 `Command+Shift+Space`。热键被占用或环境不支持时显示提示，仍可从托盘进入；Linux Wayland 的全局热键不受当前库支持。

- 选择设备后「发送当前剪贴板」：点击时采集一次，加入该设备的持久化发件箱。离线设备也可选择。
- 「获取当前剪贴板」：目标在线且已开启远程读取权限时，将其当前内容加入本机历史。只有点击历史条目的「复制到剪贴板」才改写本机剪贴板。
- 搜索已有历史；星标常用目标并记住最近选择。浏览器本地存储只保存设备 ID，不保存剪贴板正文或认证令牌。
- `Esc` 关闭面板。再次打开会刷新设备与历史。

## 提醒切换

在「AI 任务」点击「将提醒切换到这台电脑」。同一提醒组的设备需配置相同 AI 提醒令牌，并升级到支持接收端切换的版本。

接收端声明通过已认证的只读接口和现有设备轮询传播。并发切换采用逻辑序号和操作 ID 决定最终接收端。页面会显示待同步、部分确认或已确认；网络分区、离线、旧版或认证失败时，不能承诺即时全局唯一提醒。未配置提醒令牌时只切换本机开关。

关闭本机提醒不会取消另一台电脑已经取得的接收权。首次拉取某个设备的历史事件时建立基线，避免切换后重放旧提醒。本次不执行 AI 审批，也不自动控制外部 AI 应用。

## 传输中心与离线发件箱

在时间线点击条目的「发送」，再选择目标电脑；或者直接在传输中心发送当前剪贴板。可设置 1 小时、24 小时或 7 天有效期。

- 发件箱保存点击时的条目快照、精确目标设备 ID 和有效期。后台只重试这个快照，重启后仍可恢复。
- 「条目已送达」只表示对端保存了元数据和内联内容。文件仍按需下载；请保留源文件与共享历史，并让源机在下载时在线。队列不提供源机关机后的文件中转。
- 远端文件条目的「仅下载」加入下载任务，保存到现有接收目录，不写剪贴板、不自动打开文件。源于本机的文件请使用原文件，此入口不按远端提供的路径读取本机磁盘。
- 展示每个任务和文件的进度、实际已接收字节、可确定的总大小、状态与失败原因。总大小未知时不显示虚假百分比。
- 普通文件继续复用 HTTP Range 续传；目录仍需重新传输归档。重启中断的下载暂停，用户重试后恢复；已完成的文件保留。
- 可以取消、重试失败任务、移除终态记录。取消停止后续尝试，无法撤回已送达条目或已完成的文件；移除记录不会删除下载文件。
- 最多保留 128 条任务、队列文件最多 16 MiB。恢复或落盘失败时停止队列并明确报错，保留原始文件。

任务控制、快捷面板和页面资源只允许本机访问。本机界面通过校验回环地址、Host、Origin 和浏览器来源访问指定桌面接口，无需把对端认证令牌嵌入页面；网络对端仍遵循原有认证和权限开关。

## 验证入口

```powershell
cargo test --workspace --locked --offline
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked --offline
node scripts/tests/quick-panel.test.cjs
node scripts/tests/transfer-center.test.cjs
```

`desktop_tools_probe` 示例提供独立数据目录和合成离线设备，用于查看真实界面；它使用自己的可执行文件模拟 Tailscale 发现，不连接实际设备。仅使用测试目录运行，不在该页面采集真实剪贴板：

```powershell
cargo run -p peercarry-core --example desktop_tools_probe -- target/desktop-tools-ui 51991
```

本机自动化与合成网络测试不替代 Windows/macOS/Linux 实际托盘热键、真实双机提醒切换及跨网络传输验收。
