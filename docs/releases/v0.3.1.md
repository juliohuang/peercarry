# PeerCarry v0.3.1 — 自动检查更新

在 v0.3.0 的四个平台安装包基础上，补齐托盘应用的自动更新提醒。

## 更新行为

- 启动约一分钟后检查，之后默认每六小时检查一次。
- 发现新版本提醒，通过托盘「更新并重启」确认后下载、验证、替换并重启，同一版本不重复提醒。
- 已是最新版本时不弹窗；离线或检查失败不会阻止应用继续运行，可用菜单手动重试。
- 设置页可关闭自动检查或调整检查周期（1–168 小时），保存后生效。
- 保留 Ed25519 签名、SHA-256 和文件大小校验、传输忙碌保护及启动失败回滚。
- 修复旧配置中的空更新地址、公钥覆盖官方发布包默认配置的问题。自定义源不会自动继承官方信任公钥。

## 安装和升级

从 Assets 选择对应平台的完整压缩包：Windows x64 ZIP、Linux x64 tar.gz、macOS Apple Silicon tar.gz 或 macOS Intel tar.gz。
Windows 解压后运行 `Install.ps1`，macOS/Linux 运行 `sh install.sh`，具体命令见包内说明。

v0.3.0 官方包用户可以在托盘菜单点击「更新并重启」升级；已有本地开发包且未配置更新源的用户，先手动安装本版一次。
之后运行托盘即可自动检查后续版本。当前自动更新替换托盘应用及其内嵌服务，独立 CLI 请用完整安装包更新；只运行 Linux CLI 守护进程不会启动托盘更新检查。

本版仍未提供 Windows Authenticode 或 Apple 公证；更新清单签名不等同于操作系统代码签名。
四平台原生构建和自动测试不替代用户设备上的剪贴板权限、托盘交互及真实双机验收。
