# PeerCarry v0.3.0

首个 PeerCarry 桌面发行版。无需在目标电脑安装 Rust 或下载源码编译。

## 下载哪个文件

| 环境 | 下载 |
| --- | --- |
| Windows x64 | `peercarry-v0.3.0-x86_64-pc-windows-msvc.zip` |
| Linux x64（Ubuntu 22.04 及兼容环境） | `peercarry-v0.3.0-x86_64-unknown-linux-gnu.tar.gz` |
| macOS Apple Silicon（M 系列） | `peercarry-v0.3.0-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `peercarry-v0.3.0-x86_64-apple-darwin.tar.gz` |

压缩包内含托盘程序、CLI 和安装脚本。不要将 GitHub 自动生成的 Source code 文件当作安装包。

## 安装

- Windows：解压后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1`。安装到当前用户目录并启动托盘。
- Linux/macOS：解压后运行 `sh install.sh`，然后按输出提示配置启动服务。旧版用户先退出旧托盘并停用旧服务，避免两个进程共用数据库。
- Linux 桌面端需要 GTK 3、WebKitGTK 4.1、libxdo 及图形会话；纯命令行中继可使用 CLI。
- 建议各设备均升级至本版，并使用已经连接的 Tailscale 网络。

## 包含功能

- 手动共享文本、图片和文件；收到内容不会自动覆盖剪贴板。
- 文件按需下载、校验、断点续传及导出。
- Codex / Z Code Hook 接入和跨设备 AI 状态提醒，需在工具中完成绑定验证。
- PeerCarry 统一命名，并保留已有数据目录和旧协议兼容。

## 校验与限制

`SHA256SUMS.txt` 提供文件校验值，`latest.json` 是供应用更新器验证的 Ed25519 签名清单。
更新清单签名与操作系统代码签名不同：本版没有 Windows Authenticode 或 Apple Developer 公证。
macOS/Linux 为普通二进制安装包，不是 DMG、AppImage、deb 或 rpm；系统可能要求额外的应用运行许可。

各平台在 GitHub 原生运行环境编译、运行自动化测试并检查 CLI 启动。剪贴板权限、托盘交互和真实双机传输仍需要用户环境验证。
AI 提醒第一版需要手动选定接收电脑。应用内更新目前只更新托盘程序，CLI 请使用完整安装包更新。
手机端不包含在这些桌面安装包中。
